    How the hybrid works

    1. On-device (Gemini Nano, Firebase AI Logic, PREFER_ON_DEVICE): the contract's key facts — parties, amounts, term, interest/fees, late penalties, termination — are extracted on this device. Sensitive text stays private in this stage.
    2. Cloud (Gemini via Firebase AI Logic): the extracted facts are explained in plain language, with red flags and a 0–100 risk score.
    3. If this device has no on-device model, Stage 1 falls back to the cloud automatically — the badge above always shows which backend actually answered.
